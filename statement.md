# Student Study & Task Manager

## Problem Statement

College students often have multiple study tasks, assignments, and revision activities to complete. Managing these tasks manually can make it difficult to remember pending work and track study progress.

The Student Study & Task Manager is a Python-based application that helps students organize their study-related tasks in one place. Users can add tasks, view their tasks, search for a particular task, mark tasks as completed, and check their overall study progress.

## Scope

The project will provide a simple command-line system for managing study tasks. It will focus on basic task organization and progress tracking.

## Target Users

- College students
- Students preparing for examinations
- Students who want to organize their study tasks

## High-Level Features

1. Add a study task
2. View all study tasks
3. Search for a task
4. Mark a task as completed
5. View study progress

## Non-Functional Requirements

1. **Usability**  
   The system should have a simple and easy-to-understand command-line interface so that students can use it easily.

2. **Reliability**  
   The system should correctly add, search, complete, and display study tasks without unexpected errors.

3. **Maintainability**  
   The program should be divided into separate modules so that the code can be easily understood, maintained, and modified.

4. **Error Handling**  
   The system should handle invalid inputs such as empty task names and display suitable messages to the user.

5. **Performance**  
   The system should perform task operations quickly for a normal number of study tasks.
